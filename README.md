# 🎣 PhishGuard — Automated Phishing Email Triage Bot

Асинхронный Telegram-бот на базе **aiogram 3** для автоматизированного анализа подозрительных писем (`.eml`), извлечения артефактов и скоринга фишинговых угроз.

Проект разработан для автоматизации работы аналитиков 1-й линии SOC и специалистов службы информационной безопасности при обработке сообщений пользователей о подозрительной почте.

---

## ⚡️ Функциональные возможности

* **Парсинг MIME-структуры:** безопасное извлечение заголовков (`Subject`, `From`, `Date`), тела письма и почтовых проверок подлинности (`Received-SPF`).
* **Анализ вложений:** детектирование опасных исполняемых расширений (`.exe`, `.scr`, `.bat`, `.iso`) и вычисление криптографических хэшей **SHA-256** без запуска файлов.
* **Экстракция URL:** извлечение всех гиперссылок из текста и HTML-блоков письма.
* **Threat Intelligence обогащение:** проверка хэшей вложений и Base64-кодированных URL через **VirusTotal v3 API**.
* **Risk Scoring & Вердикт:** автоматический расчет уровня риска с выдачей понятной аналитической сводки (`CLEAN` / `PHISHING`).
* **Безопасность данных:** автоматическая очистка временных файлов после анализа для соблюдения конфиденциальности.

## 🚀 Запуск в Docker

1. Клонируйте репозиторий:
   \`\`\`bash
   git clone https://github.com/твой-юзернейм/phish-guard.git
   cd phish-guard
   \`\`\`

2. Настройте конфигурацию:
   \`\`\`bash
   cp .env.example .env
   # Заполните TELEGRAM_BOT_TOKEN и VIRUSTOTAL_API_KEY
   \`\`\`

3. Соберите и запустите фоновый сервис:
   \`\`\`bash
   docker build -t phish-guard .
   docker run -d --name phish-guard --restart always --env-file .env phish-guard
   \`\`\`
